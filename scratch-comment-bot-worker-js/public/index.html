Scratch Comment Bot Cloudflare Worker版

投稿キューと、所有スタジオの整理を同じ画面で管理します。

Scratchログイン

パスワードは保存せず、Workerの短期メモリにセッションだけ保持します。

投稿する文字をキューへ追加

投稿間隔はScratch側の制限に配慮して最低15秒です。

所有スタジオ整理

ログイン中アカウントが所有者のスタジオだけ読み込めます。

プロジェクトはスタジオから外すだけです。コメント削除・メンバー除外は元に戻せません。

スタジオIDを入力して読み込んでください。

投稿キュー

キューは空です。
「一括開始」まで投稿しません。「もう一度繰り返す」は実行済みの同じキューを1周だけ再実行します。

使い方

1. Scratchにログイン
2. 投稿先と文字を入力してキューへ追加
3. 一括開始で順番に投稿
4. スタジオ整理は所有確認後、対象カテゴリごとに実行
