# Scratch Comment Bot - Python版

付属のHTML画面をFlaskで配信し、Scratchログイン・指定秒数の投稿キュー・所有スタジオの整理画面をローカルで動かします。

## 起動

Windowsでは `start.bat` をダブルクリックします。起動後、ブラウザを自動で`http://127.0.0.1:8765/`に開きます。手動なら次のコマンドです。

```powershell
python -m pip install -r requirements.txt
python app.py
```

ブラウザで `http://127.0.0.1:8765/` を開いてください。

## 投稿キュー

1. Scratchアカウントでログイン
2. 投稿先・コメント・「一括開始から何秒後」を入力
3. 「キューに追加」を繰り返す
4. 「一括開始」を押す

秒数は一括開始時点からの相対時間です。投稿は直列化し、Scratch側のレート制限に配慮して最低15秒の間隔を置きます。

## 所有スタジオの整理

1. Scratchへログインし、「所有スタジオ整理」にStudio IDまたはStudio URLを入力します。
2. ログイン中アカウントが所有者であることを確認できた場合だけ、プロジェクト・コメント・キュレーター・マネージャーを一覧表示します。
3. 各カテゴリの一覧を確認し、「全件外す」「全件削除」ボタンを使うか、個別ボタンを押します。

プロジェクトの一括処理はスタジオから外すだけで、プロジェクト本体は削除されません。コメントの一括処理はコメントを削除し、キュレーター・マネージャーの一括処理はスタジオから外します。実行中は進捗表示と停止ボタンが使え、Scratch側で失敗した場合はそこで停止して結果を表示します。連続操作には短い待ち時間を設けています。

## 旧機能について

毎日予約・キーワード反応・返信抽選は現在の画面から非表示にしています。既存データファイルやバックエンドの旧ルートが残っている場合があるため、完全に機能を削除する場合は別途コードから取り除いてください。

## データと安全性

- Scratchパスワードは保存しません。ログイン中のセッションはメモリだけに保持し、プログラム終了で消えます。
- スタジオ整理の対象は所有者チェックを通過したStudioだけです。キュレーターやマネージャーを外す前に、対象ユーザー名を確認してください。
- Scratchの規約、コメント制限、レート制限を回避する機能はありません。
- 初期設定は `127.0.0.1` のみで待ち受けます。外部公開する場合は認証・HTTPS・アクセス制限を別途設定してください。
