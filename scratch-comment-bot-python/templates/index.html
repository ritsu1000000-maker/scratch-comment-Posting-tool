プログラマブルに。

イベント、コマンド、Cog、ExtensionをPythonで自由に組み合わせる。コメントからゲームも診断も会話も生み出せる、Bot開発フレームワークです。

ローカルPythonで稼働 discord.pyアーキテクチャ Scratch負荷を制御
bot.py
from scratchbot import Bot

bot = Bot(command_prefix="!")

# コメントから自由な体験をつくる
@bot.command()
async def hello(ctx):
    await ctx.send(
        f"こんにちは {ctx.author}!"
    )

bot.run()

所有スタジオ整理

ログイン中アカウントが所有者のスタジオだけ読み込めます。各カテゴリの「全件」ボタンは、件数確認後にそのカテゴリを順番に整理します。

プロジェクトはスタジオから外すだけで、コメント削除とメンバー除外は元に戻せません。実行中は停止できます。

スタジオIDを入力して読み込んでください。
